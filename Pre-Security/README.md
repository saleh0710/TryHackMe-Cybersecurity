## Repository Structure

The repository is organized to support a clear learning portfolio and lab journal:

- `README.md` — main entry point and portfolio overview
- `PROGRESS.md` — module-by-module progress tracker
- `LEARNING-LOG.md` — chronological learning journal
- `SKILLS.md` — skills inventory and emerging competencies
- `TOOLS.md` — tools, commands, and practical usage notes
- `SECURITY-NOTES.md` — safety, ethics, and responsible testing guidance
- `LICENSE` — repository license
- `Introduction to Cyber Security/` — foundational cyber security concepts
- `Computer Fundamentals/` — computer, virtualization, and cloud basics
- `Operating Systems Basics/` — OS fundamentals and command-line basics
- `Software Basics/` — software, data, and programming fundamentals
- `Network Fundamentals/` — networking and packet concepts
- `How The Web Works/` — DNS, HTTP, and web architecture
- `Cyber Security Basics/` — cyber security principles and defensive/offensive concepts
- `images/` — media and visual references

## Learning Approach

Each room and topic is documented using a simple, repeatable reflection workflow:

`Concept → Task → Practical Activity → Tools/Commands → Result → Lesson Learned → Reflection`

This format keeps the portfolio useful as both a study record and a professional artifact. It emphasizes understanding rather than memorization and encourages careful recording of what was actually learned.
