# Virtualisation Basics

This topic introduces virtualisation as a way to run isolated computing environments on a host system.

## What I Learned

- Virtualisation is used for testing, learning, and isolated environments.
- Hypervisors manage virtual machines and their resources.
- Virtual environments reduce risk when experimenting with systems or tools.

## Reflection

Virtualisation is important in cybersecurity because it allows safe, controlled practice. It also supports modern infrastructure and testing workflows in real-world environments.
