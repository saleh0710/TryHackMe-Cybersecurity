# Cloud Computing Fundamentals

This topic introduces the idea of cloud services and the main service models used in modern computing.

## What I Learned

- Cloud computing delivers on-demand computing resources.
- IaaS, PaaS, and SaaS represent different levels of control and abstraction.
- Public, private, and hybrid models affect deployment and security considerations.

## Reflection

Cloud computing is central to modern digital environments. Understanding its models helps when evaluating architecture, security, and service design.
