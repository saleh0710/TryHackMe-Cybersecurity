# DNS in Detail

This topic explains how DNS supports the internet by mapping human-readable domain names to addresses that machines can use.

## What I Learned

- DNS is a core service that enables name resolution.
- Domain names depend on a structured hierarchy of nameservers and records.
- DNS issues can disrupt access to websites and network services.

## Reflection

Understanding DNS gave me a clearer picture of how the web is navigated and why service discovery depends on reliable naming systems.
