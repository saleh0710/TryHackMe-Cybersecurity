# How Websites Work

This topic explains the relationship between client-side code, server-side systems, and the browser as part of a website experience.

## What I Learned

- A website involves several layers working together.
- Frontend and backend components support different parts of the user experience.
- Resources such as CSS, HTML, and scripts are loaded and processed by the browser.

## Reflection

This module helped connect abstract internet concepts to the tangible behaviour of websites that users interact with every day.
