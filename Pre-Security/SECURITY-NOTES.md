# Security Notes

This repository is a learning portfolio, not an answer key or a guide for unauthorized activity. The purpose is to document a structured education in cybersecurity fundamentals and responsible practice.

## Ethical Use of Security Knowledge

- Use security knowledge only in environments where I have explicit permission.
- Never test systems without authorization.
- Treat cybersecurity as a discipline grounded in responsibility, not exploitation.
- Focus on documentation, learning, and defensive understanding.

## Safe Learning Approach

- Prefer lab environments, virtual machines, and approved learning platforms.
- Keep notes on commands, concepts, and observations.
- Distinguish clearly between educational learning and real-world attack activity.
- Avoid publishing sensitive or private material.

## Portfolio Principle

This repository documents what was learned, what was practised, and what was reflected upon. If a result, answer, password, or flag was not recorded, it is marked as `Not recorded` or `Not provided` rather than invented.
