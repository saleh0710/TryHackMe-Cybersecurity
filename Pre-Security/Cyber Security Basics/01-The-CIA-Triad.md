# The CIA Triad

This topic introduces the core model for information security: confidentiality, integrity, and availability.

## What I Learned

- Confidentiality protects sensitive information from unauthorised access.
- Integrity ensures data is not modified improperly.
- Availability ensures systems and information remain accessible when needed.

## Reflection

The CIA Triad is a foundational model in cyber security because it captures the main goals security professionals seek to maintain.
