# Become a Defender

This topic explains the role of defenders in identifying, preventing, and responding to security threats.

## What I Learned

- Defensive security combines process, monitoring, and technical control.
- Detection and response are as important as prevention.
- Understanding attacker behaviour improves protective design.

## Reflection

A defender’s job is not only to block attacks but also to maintain resilience, reduce risk, and improve the security posture over time.
