# Become a Hacker

This topic focuses on the mindset and structured approach to understanding how systems can be tested and analysed ethically.

## What I Learned

- Security practice involves careful observation, investigation, and reasoning.
- Enumeration and problem solving are important parts of technical understanding.
- Ethical boundaries and authorisation are essential.

## Reflection

Learning the hacker mindset in a responsible way helps build a stronger defensive understanding, because it reveals how weaknesses can be identified and addressed.
