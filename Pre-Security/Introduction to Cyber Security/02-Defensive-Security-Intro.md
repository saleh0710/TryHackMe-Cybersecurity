# Defensive Security Intro

This topic introduces the defensive side of security, focusing on reduction of risk, strengthening controls, and improving resilience.

## What I Learned

- Defensive security focuses on prevention, detection, and response.
- Monitoring, logging, patching, and access control all contribute to a safer environment.
- Security teams must think proactively, not only reactively.

## Reflection

Defensive security is not only about tools; it is about design, process, and ongoing strategic awareness. It complements offensive security by turning knowledge of weaknesses into better resilience.
