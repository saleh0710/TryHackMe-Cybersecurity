# Offensive Security Intro

This topic introduces the concept of offensive security in a responsible and structured way. Rather than treating security as a purely destructive field, the learning focus is on how security professionals use disciplined methods to identify weaknesses and improve systems.

## What I Learned

- Offensive security is about understanding how attacks work so that defences can be strengthened.
- Ethical and authorised testing is a key principle.
- Reconnaissance, analysis, and structured investigation are important parts of professional security work.

## Reflection

Understanding offensive security helps me see why defenders need to be prepared, and why secure systems require continuous review, testing, and improvement.
