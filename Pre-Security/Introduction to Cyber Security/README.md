# Introduction to Cyber Security

This module lays the foundation for understanding cyber security as a field. It introduces the broad concepts behind offensive security, defensive security, and the role that cybersecurity careers play in protecting digital systems.

## Learning Focus

- What cyber security is and why it matters
- The difference between offensive and defensive perspectives
- The role of security professionals in protecting systems
- Career paths and foundations for continued learning

## Key Takeaways

- Security is a discipline built on understanding risk, systems, and responsible practice.
- Defensive work reduces exposure and improves resilience.
- Offensive work, when conducted ethically and with permission, helps identify weaknesses and improve security.
- A successful career in cybersecurity depends on both technical knowledge and a structured mindset.
