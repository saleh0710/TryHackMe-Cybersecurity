# Tools and Commands

This repository focuses on learning and reflection, so the tools listed here are documented in terms of their role in the learning process rather than as exhaustive security toolkits.

## Common Command-Line Concepts

| Tool / Command | Purpose | Notes |
| --- | --- | --- |
| `ls` | Lists files and folders | Used to inspect a working directory |
| `pwd` | Prints the current working directory | Useful for confirming context |
| `cd` | Changes directory | Fundamental command for navigation |
| `mkdir` | Creates a directory | Used to structure projects and labs |
| `cat` | Displays file contents | Helpful for reading notes or configuration files |
| `grep` | Searches text patterns | Used to find relevant information quickly |
| `find` | Searches for files and directories | Useful for locating content in a project |
| `curl` | Transfers data from a URL | Commonly used when learning HTTP behaviour |
| `ping` | Tests connectivity to a host | Useful for network troubleshooting conceptually |
| `nslookup` / `dig` | Query DNS records | Important for DNS learning |
| `whois` | Queries domain registration information | Useful for domain-related understanding in a legal and ethical context |
| `ssh` | Connects to a remote system securely | Common in server administration contexts |

## Learning Notes

- Command-line tools are introduced as a core part of technical learning and troubleshooting.
- Tools are documented for their educational role, not as a recommendation for unauthorized testing.
- Where exact command usage was not recorded, the command is described at a conceptual level only.
- Security tools should only be used in environments where appropriate authorization exists.
